# Security Policy

## Supported Versions

The project is in active development and only the latest version receives security updates.

| Version | Supported |
| --- | --- |
| 0.1.x | yes |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub security advisories: open the repository, choose Security, then Report a vulnerability.

If that is not possible, contact a maintainer directly on GitHub.

Include as much of the following as you can:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept
- Affected packages and versions
- Any suggested fixes

## Response Expectations

- Acknowledgement within 72 hours
- An assessment of severity and impact within 7 days
- Coordinated disclosure after a fix is available

Please do not open public issues for security reports.
