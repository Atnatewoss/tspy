## Overview
tspy brings intelligent capabilities to your full-stack apps using our integrated Python layer for LLMs and Agents.

## Capabilities
- **Agents**: Autonomous AI workflows.
- **LLM**: Direct access to top-tier LLM providers (OpenAI, Anthropic, Gemini, etc).
- **MCP**: Model context protocol integrations.
- **Prompts**: Managed prompt templating.
- **RAG**: Retrieval-augmented generation with vector databases.
