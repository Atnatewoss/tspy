# Contributing to TSPY

First off, thank you for considering contributing to TSPY.

## Development Workflow

1. Fork the repository and create your branch from `main`.
2. Ensure you have Node.js and `pnpm` installed.
3. Run `pnpm install` in the repository root.
4. Make your changes in the appropriate package.
5. Ensure your code follows the established style guidelines.
6. Run tests where applicable.

## Pull Request Process

- Ensure any install or build dependencies are removed before the end of the layer when doing a build.
- Update the README.md with details of changes to the interface, if applicable.
- The PR should work for a single clear purpose.
- Use Conventional Commits format for your commit messages.

## Bug Reports

When opening a bug report, please include as much detail as possible, including:
- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details

Thank you for your contributions.
